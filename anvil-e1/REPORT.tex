\begin{abstract}\noindent 

Anvil-E1 is a parameterized,\allowbreak{} text-only SystemVerilog embedding engine with external weight and intermediate storage. Phase 2 integrates authentic BF16 coefficients from the supplied Google EmbeddingGemma-2 checkpoint slice,\allowbreak{} executes the adopted transformer equations in hardware,\allowbreak{} and compares public RTL outputs with independent integer and floating-point software references.


All sixteen official-weight jobs passed with zero Q8.24 word mismatches. Against raw-BF16-weight FP32 software inference,\allowbreak{} minimum cosine similarity was 0.9999999998517652 and maximum absolute error was 0.000012040138244628906. These measurements cover a deterministic reduced geometry with repeated source-layer mapping,\allowbreak{} not complete-checkpoint inference or application-level embedding quality.


\end{abstract}

\section{Architecture and design rationale}

The integration root,\allowbreak{} anvil\_\allowbreak{}e\_\allowbreak{}top,\allowbreak{} contains exactly one parameter- and port-forwarding anvil\_\allowbreak{}e1\_\allowbreak{}top instance named core and adds no state or latency. Twelve implementation modules separate control,\allowbreak{} address generation,\allowbreak{} memory transport and arithmetic. A hardwired sequencer schedules reusable vector engines and one shared MAC. Weights and sequence-sized intermediates remain external; bounded vector buffers and repeated attention reads avoid an on-chip checkpoint or sequence-squared score array. This favors storage economy and explicit arithmetic boundaries over parallel throughput. Runtime division uses registered restoring arithmetic rather than wide combinational division. Sources E001–E016 describe the implementation; current measurements are supported separately by E085–E089.

\section{Behavior and corner cases}

\subsection{Adopted transformer computation}

Token embeddings are scaled by sqrt(\allowbreak{}H)\allowbreak{}. Global PLE projection is divided by sqrt(\allowbreak{}H)\allowbreak{},\allowbreak{} reshaped into distinct per-layer P-vectors and RMS-normalized. Each layer performs input norm; q/\allowbreak{}k/\allowbreak{}v projection; per-head q/\allowbreak{}k norm; RoPE; attention and o projection; post-attention norm and residual; pre-feedforward norm; GELU(\allowbreak{}gate)\allowbreak{}*\allowbreak{}up,\allowbreak{} down projection,\allowbreak{} post-feedforward norm and residual; gated PLE projection,\allowbreak{} post-PLE norm and residual; then layer\_\allowbreak{}scalar. Final RMSNorm and embedding projection precede pooling. Projections are bias-free and inference dropout is zero. These are adopted forward conventions,\allowbreak{} not demonstrated upstream executable parity.

\subsection{Attention,\allowbreak{} masks and Matryoshka output}

Attention is bidirectional. Full layers see all valid keys; local layers additionally require abs(\allowbreak{}key\_\allowbreak{}position-query\_\allowbreak{}position)\allowbreak{}<SLIDING\_\allowbreak{}WINDOW. RoPE uses split-half rotation and bases 10000/\allowbreak{}1000000 for local/\allowbreak{}full attention. Explicit masks select keys and pooling contributions; no BOS/\allowbreak{}EOS insertion,\allowbreak{} automatic PAD masking or prompt exclusion occurs. Mean pooling precedes prefix selection,\allowbreak{} and L2 normalization uses only that selected prefix.

\subsection{Fixed-point numerical contract}

External coefficients,\allowbreak{} activations and outputs are signed Q8.24 in [\allowbreak{}-128,\allowbreak{}128-2\textasciicircum{}-24]\allowbreak{}. Finite BF16 conversion and arithmetic boundaries use nearest/\allowbreak{}ties-even rounding and saturation. Complete MAC reductions retain at least 96 bits; products retain 64 bits. Nonlinear series use Q40 internals. Every weighted RMSNorm adds EPSILON\_\allowbreak{}Q48=\allowbreak{}281474977 after ties-even division of the complete Q48 square sum by count,\allowbreak{} then applies unit-offset weights. L2 has no epsilon; a nonempty zero pooled vector succeeds with zero output.

\subsection{Arithmetic defect resolution}

Quantizing epsilon first to Q8.24 had produced 17/\allowbreak{}2\textasciicircum{}24,\allowbreak{} enough to fail the official FP32 error gate despite exact integer agreement. Direct Q48 epsilon representation corrected that denominator discrepancy. Wide runtime division/\allowbreak{}remainder and mixed clocked assignment styles were subsequently removed: local 96-bit restoring dividers commit four steps per edge over 24 divide edges,\allowbreak{} followed by result consumption. The revised design preserves numerical boundaries but increases internal latency. Current functional and structural results cover these repaired sources.

\subsection{Errors and reset obligations}

Completion errors are 0 success,\allowbreak{} 1 invalid descriptor,\allowbreak{} 2 invalid token/\allowbreak{}position/\allowbreak{}mask,\allowbreak{} 3 memory error,\allowbreak{} 4 all masked and 5 address overflow. IDs are validated even when masked. Exclusive ends above 0xffffffffffffffff are rejected,\allowbreak{} including an end equal to 2\textasciicircum{}64. Rejected jobs do not emit a successful embedding. Reset cancels requests,\allowbreak{} computation and held results; the fabric must share reset or flush obsolete responses.
