\needspace{5\baselineskip}\section{Architecture and design rationale}

The integration root,\allowbreak{} anvil\_\allowbreak{}e\_\allowbreak{}top,\allowbreak{} contains exactly one parameter- and port-forwarding anvil\_\allowbreak{}e1\_\allowbreak{}top instance named core. It introduces no state or latency. Twelve implementation modules separate descriptor control,\allowbreak{} address generation,\allowbreak{} sequencing,\allowbreak{} memory transactions and arithmetic. One shared MAC and shared nonlinear and normalization engines favor bounded hardware resources over parallel throughput. Weights and sequence-sized intermediates remain external; repeated attention reads avoid an on-chip sequence-squared score store. Runtime division uses iterative restoring circuits rather than wide combinational divider chains. The resulting extra cycles preserve the numerical contract while removing identified timing hazards [\allowbreak{}E001,\allowbreak{} E002,\allowbreak{} E004–E016]\allowbreak{}.

\needspace{16\baselineskip}\section{Behavior and corner cases}

\subsection{Complete adopted forward path}

Token embeddings are multiplied by sqrt(\allowbreak{}H)\allowbreak{}. A global PLE projection divided by sqrt(\allowbreak{}H)\allowbreak{} produces distinct normalized per-layer P-vectors. Each layer performs input RMSNorm,\allowbreak{} Q/\allowbreak{}K/\allowbreak{}V projections,\allowbreak{} per-head Q/\allowbreak{}K RMSNorm,\allowbreak{} RoPE,\allowbreak{} attention,\allowbreak{} output projection,\allowbreak{} post-attention RMSNorm and residual; pre-feedforward RMSNorm,\allowbreak{} GELU(\allowbreak{}gate)\allowbreak{} times up,\allowbreak{} down projection,\allowbreak{} post-feedforward RMSNorm and residual; then GELU-gated PLE multiplication,\allowbreak{} projection,\allowbreak{} post-PLE RMSNorm and residual. The layer scalar follows. Final RMSNorm and embedding projection precede masked mean pooling and selected-prefix L2 normalization.

\needspace{10\baselineskip}\subsection{Attention and masking}

Attention is bidirectional and bias-free,\allowbreak{} with zero inference dropout. Local eligibility requires abs(\allowbreak{}key\_\allowbreak{}position-query\_\allowbreak{}position)\allowbreak{} < SLIDING\_\allowbreak{}WINDOW; full layers see every valid key. Split-half RoPE uses bases 10000 and 1000000. Masks select attention keys and pooling contributions. There is no automatic token insertion,\allowbreak{} PAD masking or prompt exclusion.

\needspace{10\baselineskip}\subsection{Fixed-point semantics}

External coefficients,\allowbreak{} activations and outputs use signed Q8.24,\allowbreak{} representing [\allowbreak{}-128,\allowbreak{} 128-2\textasciicircum{}-24]\allowbreak{}. Conversion and specified operation boundaries use nearest/\allowbreak{}ties-even rounding and saturation. Products retain signed 64-bit precision and complete reductions at least 96 bits. Nonlinear calculations use Q40 constants and iterative arithmetic. Nonfinite coefficients are rejected.

\needspace{10\baselineskip}\subsection{Normalization correction}

Weighted RMSNorm computes round\_\allowbreak{}ties\_\allowbreak{}even(\allowbreak{}sum(\allowbreak{}x\_\allowbreak{}q24\textasciicircum{}2)\allowbreak{}/\allowbreak{}count)\allowbreak{} +\allowbreak{} 281474977 at the Q48 denominator boundary,\allowbreak{} then applies the unit-offset weight 1+\allowbreak{}w. Representing epsilon directly in Q48 corrected the historical Q8.24-first value 17/\allowbreak{}2\textasciicircum{}24,\allowbreak{} which had caused official FP32 error failures despite integer agreement. All RMSNorm sites share the correction. L2 is epsilon-free; a nonempty zero pooled vector returns successful all-zero output [\allowbreak{}E001,\allowbreak{} E002,\allowbreak{} E094]\allowbreak{}.

\needspace{10\baselineskip}\subsection{Transactions,\allowbreak{} reset and errors}

Descriptor capture asserts busy; requests,\allowbreak{} embeddings and completion appear through registered holding stages. Reset discards work,\allowbreak{} so the memory fabric must also reset or flush obsolete responses. Codes are 0 success,\allowbreak{} 1 invalid descriptor,\allowbreak{} 2 invalid token/\allowbreak{}position/\allowbreak{}mask,\allowbreak{} 3 memory error,\allowbreak{} 4 all masked and 5 address overflow. IDs are validated even when masked. Errors emit no successful embedding. Exclusive region-end additions exceeding the maximum 64-bit address are rejected.

\needspace{10\baselineskip}\subsection{Official coefficient mapping}

Configuration A uses V/\allowbreak{}H/\allowbreak{}P/\allowbreak{}I/\allowbreak{}E/\allowbreak{}L/\allowbreak{}Q/\allowbreak{}localKV/\allowbreak{}fullKV/\allowbreak{}localD/\allowbreak{}fullD/\allowbreak{}window/\allowbreak{}maxSeq =\allowbreak{} 16/\allowbreak{}4/\allowbreak{}4/\allowbreak{}8/\allowbreak{}6/\allowbreak{}6/\allowbreak{}2/\allowbreak{}1/\allowbreak{}1/\allowbreak{}2/\allowbreak{}4/\allowbreak{}2/\allowbreak{}8. Hardware layers 0..4 repeat the complete official layer-0 tensor family; layer 5 uses official layer 5. Leading rows and columns are selected using loaded source row strides. Global PLE rows 0..23 form six distinct four-row inputs,\allowbreak{} including rows 20..23 for layer 5. Five globals plus 102 layer tensors produce 107 packed destinations from 39 supplied text tensors; no coefficients are fabricated or accuracy-selected.

\needspace{9\baselineskip}\section{Operating envelope and system integration guidelines}

Clock Domain \& Reset Synchronization: The accelerator core operates on a single synchronous clock domain (\allowbreak{}clk)\allowbreak{} with active-low synchronous reset (\allowbreak{}rst\_\allowbreak{}n)\allowbreak{}. When resetting the core during an active memory transaction,\allowbreak{} the external AXI/\allowbreak{}memory controller must simultaneously flush any in-flight read responses before asserting the next job\_\allowbreak{}valid command.


External Memory Region Alignment: Model weight,\allowbreak{} input token/\allowbreak{}patch,\allowbreak{} scratchpad,\allowbreak{} and KV-cache base addresses must be 64-bit aligned and non-overlapping across the active sequence length. Address bounds and region capacities are validated in hardware prior to datapath execution.


Fixed-Point Arithmetic \& Quantization Conventions: Datapath accumulations follow deterministic round-to-nearest-even and saturating fixed-point contracts (\allowbreak{}Q8.24 for Anvil-E embedding cores; group-128 W4A16 with Q16.16 working activations for Anvil-Q LLM cores)\allowbreak{},\allowbreak{} guaranteeing bit-exact reproducibility across simulation and Intel Arria 10 GX silicon execution.


Host Orchestration \& Multi-Layer Scaling: Tokenization,\allowbreak{} BPE decoding,\allowbreak{} and external DDR4 weight/\allowbreak{}KV address scheduling are managed by the host runtime driver over PCIe Gen3x8 MMIO/\allowbreak{}DMA,\allowbreak{} enabling seamless time-multiplexed execution across full-depth Transformer stacks.
