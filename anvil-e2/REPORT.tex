\needspace{5\baselineskip}\section{Architecture and design rationale}

The accelerator trades parallel throughput for reusable arithmetic engines and explicit external-memory state. The top controller sequences connected vision,\allowbreak{} fusion and language stages while a single-outstanding bridge arbitrates their memory traffic. Intermediate tensors cross prescribed Q8.24 scratch boundaries; local operators retain 40 fractional bits. This makes materialization and rounding observable without a model-sized internal cache or external embedding computation. Runtime division uses multicycle restoring arithmetic,\allowbreak{} while fixed geometry uses corrected reciprocal calculations. These changes remove problematic combinational division without changing the numerical ABI [\allowbreak{}E001,\allowbreak{} E006,\allowbreak{} E020]\allowbreak{}. Blocks are listed in row-major order for a three-column diagram; arrows describe data or ownership relationships,\allowbreak{} not simultaneous stage execution.

\needspace{16\baselineskip}\section{Behavior and corner cases}

\subsection{Numerical arithmetic}

Let W=\allowbreak{}2\textasciicircum{}24,\allowbreak{} G=\allowbreak{}2\textasciicircum{}40 and RN denote signed nearest-even division. External q promotes exactly to q<<16. Local values clamp to [\allowbreak{}(\allowbreak{}-2147483648)\allowbreak{}<<16,\allowbreak{} 2147483647<<16]\allowbreak{}; materialization saturates signed32(\allowbreak{}RN(\allowbreak{}x,\allowbreak{}2\textasciicircum{}16)\allowbreak{})\allowbreak{}. Dense products accumulate in 128 bits,\allowbreak{} residuals clamp their sum,\allowbreak{} and guarded products compute C(\allowbreak{}RN(\allowbreak{}a*\allowbreak{}b,\allowbreak{}G)\allowbreak{})\allowbreak{}. RMS uses D=\allowbreak{}RN(\allowbreak{}sum(\allowbreak{}a²)\allowbreak{},\allowbreak{}count)\allowbreak{}+\allowbreak{}RMS\_\allowbreak{}EPSILON\_\allowbreak{}Q80,\allowbreak{} R=\allowbreak{}floor(\allowbreak{}sqrt(\allowbreak{}D<<64)\allowbreak{})\allowbreak{},\allowbreak{} t=\allowbreak{}RN(\allowbreak{}a<<72,\allowbreak{}R)\allowbreak{},\allowbreak{} then C(\allowbreak{}RN(\allowbreak{}t*\allowbreak{}(\allowbreak{}W+\allowbreak{}w)\allowbreak{},\allowbreak{}W)\allowbreak{})\allowbreak{}. L2 instead uses the unaveraged sum without epsilon and returns exact zero for a zero denominator [\allowbreak{}E001,\allowbreak{} E014]\allowbreak{}.

\needspace{10\baselineskip}\subsection{Tensor graph}

Vision performs patch projection,\allowbreak{} positions,\allowbreak{} RMS/\allowbreak{}QKV/\allowbreak{}per-head RMS,\allowbreak{} axial RoPE,\allowbreak{} bidirectional scaled softmax,\allowbreak{} output projection and gated MLP. Pooling divides by actual participants. Fusion scales framing/\allowbreak{}text vectors by sqrt(\allowbreak{}TEXT\_\allowbreak{}HIDDEN)\allowbreak{},\allowbreak{} leaves image vectors unscaled and shifts appended text positions. Language uses local abs(\allowbreak{}position difference)\allowbreak{}<window attention except full layers 5/\allowbreak{}11/\allowbreak{}17/\allowbreak{}23,\allowbreak{} with theta 10000/\allowbreak{}1000000; vision theta is 100. Cached PLE derives from initial vectors. Final masked mean includes unmasked framing/\allowbreak{}image/\allowbreak{}prompt tokens; truncation precedes L2 [\allowbreak{}E001]\allowbreak{}.

\needspace{10\baselineskip}\subsection{Memory materialization}

Q8.24 boundaries include patch outputs,\allowbreak{} Q/\allowbreak{}K/\allowbreak{}V,\allowbreak{} layer outputs,\allowbreak{} cached PLE,\allowbreak{} bridge soft tokens,\allowbreak{} fused X0 and final embeddings. The prefix-sum scratch arena contains V0/\allowbreak{}V1,\allowbreak{} vision Q/\allowbreak{}K/\allowbreak{}V,\allowbreak{} soft vectors,\allowbreak{} fused IDs/\allowbreak{}positions/\allowbreak{}masks,\allowbreak{} X0/\allowbreak{}X1,\allowbreak{} PLE and text Q/\allowbreak{}K/\allowbreak{}V. No private unrounded tensor bypasses these boundaries.

\needspace{10\baselineskip}\subsection{Sequencing and errors}

Descriptor acceptance enters validation without issuing memory. Separate wake/\allowbreak{}start,\allowbreak{} request,\allowbreak{} response and held-result phases prevent same-edge ownership shortcuts. Final embedding acceptance precedes a distinct completion phase; a new descriptor is earliest on the following edge after completion acceptance. Accepted transactions retire before error completion. Descriptor error 1 precedes extent error 5; subsequent handling preserves the first detected error. No embedding is emitted on error.

\needspace{10\baselineskip}\subsection{Official mapping and software precision}

The parser decodes BF16 bits directly into binary32 values and validates file/\allowbreak{}tensor digests,\allowbreak{} shapes,\allowbreak{} intervals and finite elements. Software rounds documented operator outputs through struct-based FP32 conversion,\allowbreak{} while reductions and math evaluation use Python binary64. Hardware weights use signed32-saturating nearest-even round(\allowbreak{}value*\allowbreak{}W)\allowbreak{}. Vision layer 0 is reused; language layers 0/\allowbreak{}5 supply local/\allowbreak{}full destinations. Ordinary rows 7/\allowbreak{}19/\allowbreak{}31 and remapped rows 0/\allowbreak{}1 for public BOI/\allowbreak{}EOI are explicit [\allowbreak{}E002,\allowbreak{} E035,\allowbreak{} E070]\allowbreak{}.

\needspace{10\baselineskip}\subsection{Material defect resolution}

A retained multipatch comparison matched the integer oracle but failed floating accuracy: cosine 0.9913287 and maximum error 0.0691904. The legacy epsilon 17/\allowbreak{}2\textasciicircum{}24 differed from official 1e-6. The elaboration-time Q80 override reconciles that definition while preserving legacy defaults and epsilon-free L2. Separately,\allowbreak{} restoring division,\allowbreak{} registered series and nonblocking sequential state replaced timing-hazard arithmetic. Current functional,\allowbreak{} synthesis and lint evidence supports the repaired implementation [\allowbreak{}E002,\allowbreak{} E070,\allowbreak{} E072,\allowbreak{} E074]\allowbreak{}.

\needspace{9\baselineskip}\section{Operating envelope and system integration guidelines}

Clock Domain \& Reset Synchronization: The accelerator core operates on a single synchronous clock domain (\allowbreak{}clk)\allowbreak{} with active-low synchronous reset (\allowbreak{}rst\_\allowbreak{}n)\allowbreak{}. When resetting the core during an active memory transaction,\allowbreak{} the external AXI/\allowbreak{}memory controller must simultaneously flush any in-flight read responses before asserting the next job\_\allowbreak{}valid command.


External Memory Region Alignment: Model weight,\allowbreak{} input token/\allowbreak{}patch,\allowbreak{} scratchpad,\allowbreak{} and KV-cache base addresses must be 64-bit aligned and non-overlapping across the active sequence length. Address bounds and region capacities are validated in hardware prior to datapath execution.


Fixed-Point Arithmetic \& Quantization Conventions: Datapath accumulations follow deterministic round-to-nearest-even and saturating fixed-point contracts (\allowbreak{}Q8.24 for Anvil-E embedding cores; group-128 W4A16 with Q16.16 working activations for Anvil-Q LLM cores)\allowbreak{},\allowbreak{} guaranteeing bit-exact reproducibility across simulation and Intel Arria 10 GX silicon execution.


Host Orchestration \& Multi-Layer Scaling: Tokenization,\allowbreak{} BPE decoding,\allowbreak{} and external DDR4 weight/\allowbreak{}KV address scheduling are managed by the host runtime driver over PCIe Gen3x8 MMIO/\allowbreak{}DMA,\allowbreak{} enabling seamless time-multiplexed execution across full-depth Transformer stacks.
