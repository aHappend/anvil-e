{\sffamily\huge\raggedright\textbf{Anvil-E2 Phase 2: Official-Weight Multimodal RTL Evaluation}\par}

{\large Technical Design and Verification Report}\par

19 October 2026 (\allowbreak{}UTC+\allowbreak{}8)\allowbreak{}\par\textcolor{vulcan}{\rule{\textwidth}{0.5pt}}

\begin{abstract}

Anvil-E2 is a parameterized SystemVerilog embedding accelerator supporting text-only,\allowbreak{} vision-only and joint vision–text operation. Its memory-backed datapath implements patch embedding,\allowbreak{} vision attention,\allowbreak{} spatial pooling,\allowbreak{} vision-to-language projection,\allowbreak{} multimodal framing,\allowbreak{} text attention with per-layer embeddings,\allowbreak{} and Matryoshka prefix normalization.


The Phase 2 evaluation directly decodes the supplied official BF16 checkpoint slice and compares an independent floating software graph with actual Q8.24 RTL execution. All 29 fixed official-weight cases passed with zero output-word mismatches against the integer oracle and exact scratch-write histories. Minimum cosine similarity was 0.9999999950454138; maximum absolute component error was 0.000047340989112854004,\allowbreak{} below the required 0.002 limit. These measurements characterize explicitly remapped subnetworks,\allowbreak{} not native full-model inference.


\end{abstract}

\section{Architecture and design rationale}

The top-level controller sequences seven connected processing stages through a single-outstanding memory bridge. Reusable vision and text engines iterate over configured layers rather than replicating complete transformers. Intermediate tensors reside in host scratch memory: the diagram's tensor-flow relationships are scratch-mediated dependencies,\allowbreak{} not direct streaming connections. Guarded Q40 local arithmetic limits intermediate rounding while preserving Q24 memory boundaries. Registered arithmetic helpers and explicit clock ownership trade additional cycles for multicycle operation. E001,\allowbreak{} E008 and E020 describe the implementation and sequencing.

\section{Behavior and corner cases}

\subsection{Multimodal computation}

Vision executes patch/\allowbreak{}position projection,\allowbreak{} RMS-normalized Q/\allowbreak{}K/\allowbreak{}V,\allowbreak{} per-head normalization,\allowbreak{} axial RoPE,\allowbreak{} bidirectional scaled softmax,\allowbreak{} residuals and gated MLP. Spatial pooling divides by actual participants. Framing and ordinary text vectors receive sqrt(\allowbreak{}TEXT\_\allowbreak{}HIDDEN)\allowbreak{} scaling; bridge image vectors remain unscaled. Text uses full attention at zero-based layers 5/\allowbreak{}11/\allowbreak{}17/\allowbreak{}23 and local attention elsewhere,\allowbreak{} with abs(\allowbreak{}position difference)\allowbreak{} < SLIDING\_\allowbreak{}WINDOW. Final pooling includes all unmasked framing,\allowbreak{} image and prompt tokens.

\subsection{Fixed-point arithmetic}

Let W=\allowbreak{}2\textasciicircum{}24,\allowbreak{} G=\allowbreak{}2\textasciicircum{}40 and RN denote signed nearest-even division. External q promotes as q<<16; materialization saturates RN(\allowbreak{}x,\allowbreak{}2\textasciicircum{}16)\allowbreak{} to signed32. Dense products accumulate in 128 bits and return C(\allowbreak{}RN(\allowbreak{}sum,\allowbreak{}W)\allowbreak{})\allowbreak{}; residuals use C(\allowbreak{}a+\allowbreak{}b)\allowbreak{},\allowbreak{} guarded products C(\allowbreak{}RN(\allowbreak{}a*\allowbreak{}b,\allowbreak{}G)\allowbreak{})\allowbreak{}. C clamps to the promoted signed32 range. RMS uses D=\allowbreak{}RN(\allowbreak{}sum of squares,\allowbreak{}count)\allowbreak{}+\allowbreak{}RMS\_\allowbreak{}EPSILON\_\allowbreak{}Q80,\allowbreak{} R=\allowbreak{}floor(\allowbreak{}sqrt(\allowbreak{}D<<64)\allowbreak{})\allowbreak{},\allowbreak{} t=\allowbreak{}RN(\allowbreak{}a<<72,\allowbreak{}R)\allowbreak{},\allowbreak{} then C(\allowbreak{}RN(\allowbreak{}t*\allowbreak{}(\allowbreak{}W+\allowbreak{}weight)\allowbreak{},\allowbreak{}W)\allowbreak{})\allowbreak{}. L2 uses the square sum without epsilon and returns exact zero for a zero denominator.

\subsection{Memory and output ordering}

Q24 materialization occurs at patch vectors,\allowbreak{} vision/\allowbreak{}text Q/\allowbreak{}K/\allowbreak{}V,\allowbreak{} layer outputs,\allowbreak{} cached PLE,\allowbreak{} projected soft tokens,\allowbreak{} fused initial vectors and final embeddings. Scratch contains vision ping-pong vectors and Q/\allowbreak{}K/\allowbreak{}V,\allowbreak{} soft vectors,\allowbreak{} fused IDs/\allowbreak{}positions/\allowbreak{}masks,\allowbreak{} text ping-pong vectors,\allowbreak{} PLE and text Q/\allowbreak{}K/\allowbreak{}V. No private unrounded tensor bypasses scratch. Matryoshka output truncates the pooled projected vector before L2 normalization.

\subsection{Control and errors}

Descriptor capture,\allowbreak{} validation,\allowbreak{} clock wake,\allowbreak{} stage start,\allowbreak{} command capture,\allowbreak{} request,\allowbreak{} response and internal result occupy distinct phases. Reset has priority. Errors stop subsequent stages and emit no embeddings; accepted transactions retire before abort completion. Codes are 0 success,\allowbreak{} 1 descriptor/\allowbreak{}mode/\allowbreak{}dimension/\allowbreak{}geometry/\allowbreak{}alignment,\allowbreak{} 2 fetched ID/\allowbreak{}position/\allowbreak{}mask,\allowbreak{} 3 memory response,\allowbreak{} 4 all-masked pooling,\allowbreak{} 5 address/\allowbreak{}extent overflow and 6 arithmetic/\allowbreak{}internal protocol. Descriptor error 1 precedes extent error 5.

\subsection{Technical repairs}

A retained multipatch evaluation matched the integer oracle but failed floating comparison,\allowbreak{} with cosine 0.9913286747 and maximum component error 0.0691903979. The legacy RMS epsilon was 17/\allowbreak{}2\textasciicircum{}24 rather than the supplied model's 1e-6. A fixed,\allowbreak{} fully propagated Q80 override reconciled the definitions without changing fixtures or thresholds. Separately,\allowbreak{} runtime combinational division/\allowbreak{}modulo and clocked blocking temporaries were replaced by restoring division,\allowbreak{} registered recurrences,\allowbreak{} constant-geometry helpers and nonblocking state updates. The current measurements include the resulting internal latency changes.

\section{Verification methods and measured results}

\subsection{Direct official-weight provenance and independent precision paths}

\textbf{Method.} Validate complete-file and tensor hashes against the supplied manifest,\allowbreak{} header agreement,\allowbreak{} BF16 dtype,\allowbreak{} shapes,\allowbreak{} bounds,\allowbreak{} intervals,\allowbreak{} original range lengths and finite values. Cross-check supplied JSON coordinates against directly decoded weights.

\textbf{Result.} Decoded 55 tensors containing 2,\allowbreak{}566,\allowbreak{}786 finite BF16 elements. Parser checks established consistency with the supplied manifest,\allowbreak{} not independent remote authentication. Floating boundaries use struct-based binary32 conversion with documented binary64 reductions/\allowbreak{}math. Hardware images use signed32-saturating nearest-even Q24 quantization.

{\small Evidence: E035,\allowbreak{} E042,\allowbreak{} E074}

\subsection{All 29 predetermined official-weight cases}

\textbf{Method.} Compile actual top-level RTL with iverilog -g2012 -Wall and execute vvp through public pins at seed 17: A has 12 mode/\allowbreak{}prefix cases,\allowbreak{} C three,\allowbreak{} D 12 and B two. Compare every output and scratch-write history.

\textbf{Result.} 29/\allowbreak{}29 passed with zero output-word mismatches and exact scratch histories. A covers dimensions 6/\allowbreak{}4/\allowbreak{}2/\allowbreak{}1; C dimension 12 with 16 vision/\allowbreak{}24 text iterations; D dimensions 768/\allowbreak{}512/\allowbreak{}256/\allowbreak{}128; B vision/\allowbreak{}joint dimension 12. Minimum cosine was 0.9999999950454138 and maximum component error 4.7340989112854004e-5,\allowbreak{} satisfying >=\allowbreak{}0.999 and <=\allowbreak{}0.002. All cases passed finite/\allowbreak{}nonzero,\allowbreak{} absolute unit-norm-error and software/\allowbreak{}RTL norm-difference requirements,\allowbreak{} with both norm limits 0.002.

{\small Evidence: E074,\allowbreak{} E042}

\subsection{Multipatch fidelity and geometry}

\textbf{Method.} Use unchanged B 4x5 geometry,\allowbreak{} two vision heads,\allowbreak{} kernel 3,\allowbreak{} six text layers and four soft tokens. Assert 20 distinct patches,\allowbreak{} nonzero positions on both axes,\allowbreak{} multiple eligible keys and pooling participant counts 9/\allowbreak{}6/\allowbreak{}3/\allowbreak{}2.

\textbf{Result.} Vision-only MAE/\allowbreak{}RMSE/\allowbreak{}vector L2-distance were 2.4860103925069172e-5 /\allowbreak{} 2.8736116710771375e-5 /\allowbreak{} 9.954482831057014e-5; joint values were 1.8387412031491597e-6 /\allowbreak{} 2.2515091304963853e-6 /\allowbreak{} 7.79945641544993e-6. RTL norms were 1.0000000229083967 and 1.0000000164914427. Respectively,\allowbreak{} 1118/\allowbreak{}1271 scratch addresses and 1688/\allowbreak{}2126 writes matched.

{\small Evidence: E074,\allowbreak{} E002}

\subsection{Per-mode RTL latency}
